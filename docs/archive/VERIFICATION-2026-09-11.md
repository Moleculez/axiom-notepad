## Browser limitations

Firefox initially followed a local system proxy and failed to reach localhost; the test launcher now disables proxy auto-configuration for that browser. This changes test launches only, not application networking.

WebKit's binary Blob persistence error was fixed by storing typed arrays; existing Blob caches remain readable. PDF pinning, private offline annotation writes, reconnection/revocation, and other reading/settings tests now pass in WebKit.

However, this Playwright WebKit build rejects `page.reload()` under `context.setOffline(true)` with “WebKit encountered an internal error.” A separate minimal HTTP page with a cached service worker and no Axiom code reproduced the same failure after confirming an active controller and cached HTML. The test is explicitly skipped for WebKit, not counted as a pass. Offline reload on real Safari/iOS remains unverified. Playwright's [service-worker automation documentation](https://playwright.dev/docs/service-workers) also limits its supported service-worker tooling to Chromium; that documentation alone does not diagnose this particular failure.
